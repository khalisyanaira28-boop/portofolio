KHALISYA PORTFOLIO — DESAIN SESUAI REFERENSI VIDEO

1. Ekstrak isi ZIP ke D:\portfolio-golang (atau folder baru).
2. Di terminal VS Code: cd D:\portfolio-golang
3. Jalankan: go run .
4. Buka http://localhost:8080

File utama:
- main.go = server Go
- templates/index.html = konten HTML
- static/css/style.css = desain
- static/js/script.js = interaksi
